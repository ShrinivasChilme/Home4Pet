# 🐾 Home4Pet

A full-stack pet adoption platform built with **React, Spring Boot, MySQL, JWT Authentication, and Stripe Payment Integration**.

---

## 📌 Features

- 🔐 JWT Authentication & Role-Based Authorization
- 👤 Multiple User Roles (Admin, Owner, Adopter, Shelter, NGO)
- 🐶 Pet Listing & Management
- ❤️ Favorite Pets
- 📋 Adoption Request Workflow
- 💳 Stripe Payment Integration
- 💬 AI Chat Support
- 🔔 Notifications
- 👤 User Profile Management
- 📱 Responsive UI

---

## 🛠 Tech Stack

### Frontend
- React.js
- Vite
- Axios
- Tailwind CSS
- React Router

### Backend
- Spring Boot
- Spring Security
- JWT
- Spring Data JPA
- Maven

### Database
- MySQL

### Payment
- Stripe
